Exam Day Checklist

⚠ Read the scope carefully — note ALL in-scope IPs/ranges before doing anything.
  • Read scope carefully — note ALL in-scope IPs/ranges
  • Setup dirs: mkdir -p ~/exam/{nmap,creds,loot,screenshots,notes}
  • Start notes file immediately — log EVERYTHING with timestamps
  • Screenshot every flag + steps that led to it (hostname && whoami && cat flag.txt)
  • Start report draft on Day 1 — never leave to the end
  • Track all credentials found (username:password/hash + where found)
  • Track all hosts (IP, OS, ports, access level, flags)
  • Methodology: RECON → SCAN → ENUMERATE SERVICES → FIND VULNS → EXPLOIT → POST-EXPLOIT → PIVOT → REPEAT

When Stuck

  • Re-enumerate — run full port scan if you only did top 1000
  • Check UDP ports
  • Enumerate web apps more thoroughly (more wordlists, more extensions)
  • Try harder on credentials (spray, reuse, default creds)
  • Run linPEAS/winPEAS again — you may have missed something
  • Run BloodHound if in AD environment — look for paths you haven't tried

Nmap Cheatsheet

Always run fast scan first, then full port scan in background.

Always Start Here

BASH
# Fast scan first
nmap -sV -sC --open -oA nmap/initial <IP>

# Full port scan (background)
nmap -p- --min-rate 5000 -oA nmap/allports <IP>

# Targeted version scan on found ports
nmap -sV -sC -p <ports> -oA nmap/targeted <IP>

# UDP (top 100)
sudo nmap -sU --top-ports 100 -oA nmap/udp <IP>

Key Flags

FlagDescription
-sVService/version detection
-sCDefault scripts
-sUUDP scan
-sSSYN scan (stealth, root)
-p-All 65535 ports
--openShow only open ports
--min-rate 5000Speed up
-AOS + scripts + traceroute
-oAOutput all formats
-PnSkip host discovery
-nNo DNS resolution

Web Attacks Overview

Methodology

  • Enumerate all technologies (Wappalyzer, whatweb, headers)
