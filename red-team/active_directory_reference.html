User Enumeration
Build a target user list using unauthenticated and credentialed techniques across SMB, LDAP, and RPC.
📂 SMB NULL Session
LINUX
Enumerate users over SMB without credentials (NULL session). Works on older/misconfigured DCs.
enum4linux -U 172.16.5.5 | grep "user:" | \ cut -f2 -d"[" | cut -f1 -d"]"
smbclient -N -L \\\\<target_ip> smbclient -L //10.10.10.178 -U ""
crackmapexec smb 172.16.5.5 --users netexec smb 10.10.11.236 -u guest -p '' --rid-brute
🔌 RPC Enumeration
LINUX
Use rpcclient for NULL-session enumeration and RID cycling to brute-force SIDs.
rpcclient -U "" -N 172.16.5.5 rpcclient $> enumdomusers rpcclient $> queryuser <RID>
# RID cycling with Impacket lookupsid.py 0xdf@manager.htb -no-pass lookupsid.py 0xdf@manager.htb -no-pass | \ grep SidTypeUser | cut -d' ' -f2 | \ cut -d'\' -f2 | tr '[:upper:]' '[:lower:]' | tee users
📋 LDAP Anonymous Enumeration
LINUX

Kerberoasting
Request TGS tickets for accounts with SPNs and crack them offline. Requires any valid domain user credential.
🐧 From Linux — GetUserSPNs.py
LINUX

CRITICAL

2

4
